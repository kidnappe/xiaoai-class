⬇ 看脚本源码
分步详解（存 3 步 · 用 4 步）与三点注意
第一次：把书签存进书签栏（只需一次）
  1. 点上方「📚 复制提取书签」
  2. 让浏览器显示书签栏：按 Ctrl+Shift+B（Chrome / Edge）
  3. 在书签栏空白处右键 →「添加网页」，标题填「提取课表」，网址框里 Ctrl+V 粘贴 → 保存
以后每学期：点书签提取
  1. 登录教务系统进入「📖 个人课表」，先在页面上的学期下拉框里选中要提取的那个学期（这一步决定提取哪个学期，不能省）
  2. 点一下书签栏的「提取课表」—— 它不直接出结果，而是把「📚 提取课表」按钮装到页面右下角
  3. 点右下角那个按钮，等浮窗显示「✅ 已复制 N 条课表」，JSON 已经进了剪贴板
  4. 回本页「4 · 粘贴课程 JSON 并导入」，点「📋 从剪贴板粘贴」
三点注意
  • 书签依赖后端在线：它只是「去取脚本」的入口。本地用要保持 启动导入器.bat 开着；点了没反应，先重启服务、或回本页重新复制一次书签。排错：F12 → 网络 → 看有没有一条 api/jiaowu_extractor.js 请求。
  • 后端地址在「点复制」那一刻固化进书签：之后换了后端（比如改用 ?api= 指向线上地址）要重新复制并覆盖旧书签。
  • 必须用 http 打开本页：直接双击 index.html（file://）生成的书签地址是坏的。
🥈 油猴脚本（一次安装，按钮常驻） 长期常用可选

需先装浏览器扩展 Tampermonkey。装好后教务页面右下角会出现「📚 提取课表」按钮，不用每次点书签。注意：油猴脚本不会自动更新，日后要用新功能得回本页重新覆盖粘贴一次。

没装？去装 Tampermonkey
安装步骤（4 步）
  1. 浏览器装好 Tampermonkey 扩展
  2. 点上方「📋 复制油猴脚本内容」
  3. Tampermonkey 面板 →「添加新脚本」→ 编辑器里 Ctrl+A 全选 → Ctrl+V 粘贴 → Ctrl+S 保存
  4. 登录教务系统，任意页面右下角出现「📚 提取课表」→ 点它 → 等浮窗显示「✅ 已复制 N 条」
📎 上传教务导出的课表表格（.xls / .xlsx）

你的教务系统如果能「导出课表为 Excel」（教务里通常在个人课表页顶部或右键菜单），可以直接选文件解析，不需要装扩展、不需要点书签，一次拿到整学期。表格结构不依赖任何接口字段，因此也不会出现星期偏移、节次认错这类问题。

手机端请用系统浏览器打开本页（微信内置浏览器常不弹文件选择）

⚠ 一个已知限制：教务导出的表格里只有「第一大节 / 第二大节」这种节次号，没有每节课的上下课时刻（那个只能从接口里的 qssj/jssj 或官方作息表拿）。所以解析后请务必在下方「课表设置」里点 ☀ 夏令时 / ❄ 冬令时（识别到河南师大时会自动选中），或手填时间表，否则导入小爱后时间会不准。

📘 完整流程（书签版，5 步）
  1. 存下提取书签：点「📚 复制提取书签」→ 按 Ctrl+Shift+B 显示书签栏 → 书签栏右键「添加网页」→ 网址框粘贴 → 保存。（只需做一次）
  2. 打开教务课表：输入框填学校地址（如 jwc.htu.edu.cn）→ 点「🔑 打开登录页」登录 → 进入「📖 个人课表」→ 在学期下拉框选中目标学期。
  3. 点书签：点一下书签栏的「提取课表」→ 页面右下角出现「📚 提取课表」按钮（书签只负责把按钮装上，不直接出结果）。
  4. 点按钮提取：点右下角按钮 → 自动识别学期代码 + 逐周扫描全学期 + 合并单双周 → JSON 复制到剪贴板 → 页面显示绿色浮窗「✅ 已复制 N 条课表」。
  5. 导入到小爱：回本页下方「4 · 粘贴课程 JSON 并导入」区 → 点「📋 从剪贴板粘贴」（或直接 Ctrl+V）自动填入并解析预览 → 在「3 · 选择目标课表」下拉选一个小爱已有课表或新建 → 可勾选「导入前清空」「同步课表设置」→ 点「🚀 导入到小爱」。

学期从页面的学期下拉框读取，提取浮窗会写明「学期 X，来源 Y」便于核对；识别不到时（提取报错带学期码）可右键教务页面的「📚 提取课表」按钮 → 手动钉死学期代码（如 202601 代表 2026 秋季学期）。长期用更省事可改用下方「🥈 油猴脚本」，一次安装后按钮常驻。

🤖 智能提取（油猴/书签都用不了时的兜底）

支持三种粘贴内容，点「智能提取」自动识别：
① 教务接口 JSON 原文（F12→网络→getCalendarWeekDatas→响应，整段复制）
② 课表页面文字：Ctrl+A 全选 → Ctrl+C 复制 → 粘贴
③ 手打一行一门课：周一 第1-2节 高等数学 张三 教1-101 1-16周(单)

3 · 选择目标课表

课程将写入选中的课表；也可以新建一个（例如「2026 春」），导入后再去小爱 App 里切换。

4 · 粘贴课程 JSON 并导入

标准格式：[{"name":"高等数学","teacher":"张三","position":"A101","day":1,"sections":"1,2","weeks":"1-16周(单)"}] —— 字段名宽松兼容（courseName/老师/教室/星期 都认），周次支持 1-16周(单)、1至16 等写法。乘方提取脚本输出的 {"courses":[...],"schedule":{...}} 整体粘贴也认。

课表设置（节数 / 时间表）

来自教务系统的课表设置，导入时一并同步到小爱（合并到现有 setting，不清空背景等）。节数和时间可手动修改。

5 · 管理课表

查看当前课表已有课程、单条删除、全部清空，或导出为标准 JSON 备份/迁移。
