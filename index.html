书签提取
源码
使用步骤与注意事项
  1. 点「复制提取书签」，按 Ctrl+Shift+B 显示书签栏。
  2. 书签栏右键「添加网页」，标题填「提取课表」，网址框粘贴后保存。
  3. 在教务「个人课表」选好学期，点书签，再点右下角「提取课表」。
  4. 回本页，点「从剪贴板粘贴」。
  • 书签需要本页服务在线；点了没反应就重启服务或重新复制书签。
  • 换过后端地址后，需要重新复制并覆盖旧书签。
  • 本页必须用 http 打开，file:// 生成的书签不可用。

安装步骤
  1. 安装 Tampermonkey。
  2. 点「复制脚本」，在 Tampermonkey 新建脚本、粘贴并保存。
  3. 在教务页点右下角「提取课表」。
